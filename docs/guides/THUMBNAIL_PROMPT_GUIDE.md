# THUMBNAIL PROMPT GUIDE (Retrofit AI brand) — the owner, 2026-06-23

The standing template for the VERTICAL 9:16 YouTube-Shorts thumbnail prompt in step 9 of the pipeline.
Output it in `projects/<slug>/post.md` as a copy-paste block, with the topic-specific bits filled in.

## Hard rules (keep, every time)
- VERTICAL 9:16. Premium creator-brand, clean / modern / minimal. LIGHT off-white background by
  default (paper texture + subtle purple gradient glow) — only go dark if the TOPIC genuinely demands it.
- Reference the owner's OWN photo as the creator cutout (placeholder — he pastes his face into his image AI).
  NEVER generate a fake face.
- Fill the `{...}` slots per video: `{HEADLINE 3-6 words}`, `{EXPRESSION}` (match the topic — surprised,
  impressed, curious, skeptical, excited, confused, concerned, confident...), and `{TOPIC OBJECT}` (the one
  single large topic-related object/graphic/UI/icon/screenshot/product/chart/symbol).
- Brand palette is fixed: Purple `#6C3BFF`, Cyan `#6EF7FF`, White `#FFFFFF`, near-black text `#111111`.

## Template (fill the `{...}` slots, then paste into post.md)

```
Vertical 9:16 YouTube Shorts thumbnail.

Premium creator-brand design with a clean, modern, minimal aesthetic.

Background: soft off-white paper texture with subtle depth and gentle purple gradient glow. Minimal visual noise. Lots of negative space. Small abstract dots, lines, or geometric accents for visual interest.

Typography: huge bold condensed sans-serif headline occupying the upper half of the canvas — "{HEADLINE 3-6 words}". Maximum 3-6 words. Strong hierarchy. Highlight key words using the brand accent colors.

Composition:

- Strong readability on mobile screens
- No excessive effects

Color palette:

Style references:
- Apple keynote presentation

```
