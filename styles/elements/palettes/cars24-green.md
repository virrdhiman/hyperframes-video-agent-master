# Palette — Cars24 green (cutout explainer)

Measured from the Cars24 reference Short (`styles/fb_ref/cars24/`).

| role | hex | notes |
|------|-----|-------|
| BG square (base) | `#143E30` | deep pine green, cutting-mat base |
| BG grid line | `#2E6149` | lighter green, ~1px on ~80px lattice |
| accent yellow | `#F5C518` | progression UP arrows, highlights |
| stamp red | `#C0392B` | diagonal rubber stamp (REGISTERED/APPROVED) |
| panel white | `#FBFAF6` | photo cards / label plates, soft shadow |
| ink (text on plates) | `#1A1A1A` | bold condensed labels |

CSS vars:
```css
--c24-bg:#143E30; --c24-grid:#2E6149; --c24-yellow:#F5C518;
--c24-red:#C0392B; --c24-panel:#FBFAF6; --c24-ink:#1A1A1A;
```
Pair with: chroma-keyed cutout host + soft contact shadow. Keep grid contrast low for legibility.
