# Palette — Vaibhav style (lime on shifting gradient)

Sampled hex from the reference reel frames (`topic_fetch/style_reel_2/fr/`). Use these EXACT values.

| Role | Hex | Use |
|---|---|---|
| **Lime accent** | `#C4FB00` | NUMBERS ONLY (the `01`–`NN` glyphs). Nowhere else. |
| Hash glyph | `#A5A5A5` | the silver `#` sitting left of each number |
| Caption white | `#F9F6FA` | bold caption text under the number |
| BG top (all sections) | `#F2F1F4` | top of the vertical background gradient (near-white) |
| BG bottom — red section | `#8D2B24` | brick-red gradient foot (e.g. the "vs Google" beat) |
| BG bottom — neutral section | `#1A1A1A` | near-black gradient foot (e.g. stat / list beats) |
| BG mid (neutral) | `#D0CFD2` | light-gray midpoint of the white→black gradient |
| PiP warm interior | `~#563718` | wood/skin warm tone of the talking-head PiP |

## Rules
- **Single-accent discipline:** `#C4FB00` is reserved for the numbers. Captions/labels stay neutral
  white/gray. This restraint is what reads "premium," not cluttered.
- **Per-section gradient:** keep the TOP near-white `#F2F1F4`; swap the BOTTOM tone per item
  (red `#8D2B24`, black `#1A1A1A`, …) so a long video stays fresh without changing the system.
- Comparison-diagram brand tints: Apple = dark red, Google = blue (native brand cues), labels in SF Pro.
- iOS mockups keep their native Apple UI colors (don't recolor real screenshots).
