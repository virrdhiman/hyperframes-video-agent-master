# Palette — webveda "Rule of 100"

Sampled hex from the reference reel. Use these EXACT values.

| Role | Hex | Use |
|---|---|---|
| Primary electric blue | `#1D31FA` | caption highlight boxes + circle-wipe reveals — THE signature |
| Big-number blue | `#3B82F6` | giant "100"/numbers (slightly lighter than box blue) |
| Accent yellow | `#FFD400` | intro hero circle fill + emphasis backdrops |
| Hero red | `#FF0000` | distressed/PNG-style emphasis word ("DREAM") |
| Text white | `#FFFFFF` | captions, headlines |
| Base near-black | `#0A0A0A` | dark backdrops |

- Brand platform icons keep their NATIVE colors (IG gradient, YT red, etc.) as sticker accents.
- High contrast throughout; the blue + yellow + red trio carries the brand energy.
