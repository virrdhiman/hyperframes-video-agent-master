# Palette — Postiz promo (violet / dark)

Sampled hex from `hf-agent/projects/postiz/index.html`. Use these EXACT values.

| Role | Hex | Use |
|---|---|---|
| Violet (`--vio`) | `#a855f7` | primary accent, dots, glows |
| Violet light (`--vio-lt`) | `#c084fc` | highlights, kicker text |
| Violet dark (`--vio-dk`) | `#7c3aed` | gradients (also `#962fbf`) |
| Ink base | `#0b0a12` | page background |
| Panel dark | `#100d1a` / `#1a1626` | cards, calendar card |
| White | `#ffffff` | text, CTA card |

Glows: `rgba(168,85,247,…)` (violet) box-shadows / text-shadows.
Mac window-chrome traffic lights (b-roll panels): `#ff5f57` `#febc2e` `#28c840`.
Brand social glyphs keep native colors (IG `#feda75…#d62976`, FB `#1877f2`, etc.).
